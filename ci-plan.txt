Plan wdrożenia CI (GitHub Actions - automatyczne testy)

KROK 1 — Stworzenie pliku workflow
  - Stwórz plik: .github/workflows/tests.yml
  - Musi być dokładnie taka ścieżka, GitHub szuka workflow'ów w .github/workflows/
  - W pliku YAML definiujesz:
    1. name: nazwa workflow (np. "Run tests")
    2. on: kiedy odpalić (push na main, pull_request do main)
    3. jobs: definicja zadania
       - runs-on: ubuntu-latest
       - steps:
         a) checkout kodu (actions/checkout)
         b) instalacja Pythona (actions/setup-python)
         c) instalacja zależności (pip install)
         d) odpalenie pytest

KROK 2 — Dodanie pytest do zależności
  - pytest nie ma w requirements.txt ani pyproject.toml
  - Dodaj go tak, żeby GitHub mógł go zainstalować
  - Opcje:
    a) dodać do requirements.txt
    b) dodać jako dev dependency w pyproject.toml (wymaga uv/pip install -e .[dev])

KROK 3 — Push na GitHub
  - git add .github/workflows/tests.yml
  - git commit + git push na main
  - Od teraz GitHub odpala testy automatycznie
  - Wynik zobaczysz w zakładce Actions na github.com/DomienGit/YTLottery
